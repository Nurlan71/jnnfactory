JNN Admin — 5 обязательных фич

1. WYSIWYG (TinyMCE CDN)

Редактор загружен через CDN. Форматируй текст, добавляй ссылки — результат виден сразу в предпросмотре.

2. Media Library

Папка: /var/www/jnnfactory/assets/. Файлы: img_11be4312ff81.jpg, 1.jpg, 2.jpg, 260A1229.jpg и т.д.

Для вставки фото используй в HTML: <img src="/assets/имя.jpg">

3. RBAC (базовая защита)

Доступ к админке ограничен: требуется пароль jnnfactory при входе.

Если нужно — можно добавить роли (Редактор / Админ).

4. Версии (резервные копии)

При каждом сохранении через «Сохранить» копия текущего HTML сохраняется в /var/www/jnnfactory/admin/backups/ с меткой времени.

Откат: замени текущий файл копией из backups.

5. SEO-блок

Для каждой страницы можно задать:

  • Title — <title>...</title>
  • Description — <meta name="description" content="...">
  • URL / ЧПУ — имя файла .html
  • Редиректы — через nginx (настрой в /etc/nginx/)

Визуальный редактор + предпросмотр выше показывают результат.
