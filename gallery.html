Чтение галереи открыто, запись (загрузка, переименование, удаление, папки) — только с ключом. Ключ хранится в этом браузере. Если файл используется или отслеживается Git, интерфейс покажет предупреждение и предложит подтвердить действие. Для Git-файлов удаление/переименование стагируется через git rm/git mv: после этого нужен commit, иначе деплой будет заблокирован.
Главное фото товара — верхнее (первое по порядку) фото в галерее товара. Порядок и перестановка выполняются в Directus, перетаскиванием за иконку-ручку в разделе «Товары». В этой галерее порядок не меняется.
Фото товара файл не выбран
Имя создаётся автоматически по slug товара: {slug}.jpg, {slug}1.jpg, {slug}2.jpg. Для Directus нужен серверный токен; для уже загруженных в нативную админку файлов используйте кнопку «SEO-имя» на карточке.
Папки виртуальные: файлы остаются по адресам /assets/<file>, поэтому карточки товаров и Git-деплой не ломаются. Создание внутри текущей папки делает подпапку; «Переместить» меняет только структуру галереи.
